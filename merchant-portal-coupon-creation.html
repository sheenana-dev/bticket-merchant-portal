4-Step Coupon Creation Flow

Step 1

Basic Details

Title, description, discount type/value, original price (discounted auto-calculated), category, branch selection, validity dates, available hours, payment methods.

Step 2

Photos & Terms

Upload up to 5 photos (first = cover), set numbered redemption terms. Tip banner shows photos increase collections by 3x.

Step 3

Redemption Rules

Frequency (daily/weekly/monthly/one-time), daily cap, total stock, auto-pause toggle, show remaining count toggle, refresh time.

Step 4

Review & Submit

Full summary table + live phone preview showing exactly how consumers will see the coupon. Submit sends it to admin for approval (24h turnaround).

After Submit

Admin Approval

Admin reviews in Admin Portal → Approve (goes live) / Reject (with reason) / Request Changes. Merchant gets notification either way.

Key Feature

Save as Draft

Available on every step. Merchant can start creating, save, and come back later. Drafts appear in "My Coupons" with a draft badge.
