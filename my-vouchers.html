What Changed & Why

Added

Savings Summary Bar

Shows "₱2,350 saved this month" + redemption count. Reinforces subscription value — the user sees their ₱99/mo is paying off massively.

Added

Filter Tabs

All / Active / Expiring / Redeemed tabs let users quickly find what they need. "Expiring" tab creates urgency to use coupons before they're gone.

Added

Expiry Dates on Every Card

The current design shows NO expiry dates. Users don't know if a coupon expires today or next month. Now each card shows exactly when, with color-coded urgency.

Added

Price Breakdown on Cards

Each card now shows ₱900 → ₱450 with a 50% OFF badge. Users instantly see the value of each coupon without opening it.

Removed

"Exclusive to B-ticket" Badge

This is a marketing label, not useful info. Replaced with expiry dates and pricing — things the user actually needs to make a decision.

Added

Orange Border for Expiring

Coupons expiring within 24h get a left orange border + "⚠ Expires in 3 hours" warning. Visual urgency drives redemption.

Added

"Use Now →" Action

Each card has a clear action link. One tap goes straight to the redemption screen. No confusion about what to do next.

Added

Redeemed State

Used coupons are faded with a "REDEEMED" stamp and "Used on Mar 15" date. Users can still view receipts. Clear visual separation from active coupons.

Expiry Rules Summary

Rule

7-Day Claim Window

After collecting, subscriber has 7 days to redeem at the store. Long enough to plan a visit, short enough to create urgency. Can be adjusted per merchant.

Rule

Merchant End Date Overrides

If a merchant's promo ends in 3 days and a user collects it, the claim expires in 3 days — not 7. The earlier date always wins.

Rule

Auto-Sort by Urgency

Expiring-soon coupons automatically sort to the top of My Vouchers. Users see what needs attention first without scrolling.

Rule

Recollect After Expiry

If the merchant's coupon is still active after a claim expires, the user can recollect it — starting a fresh 7-day window. No penalty for letting it lapse.

Rule

4 Push Notifications Max

Per coupon: Day 0 (collected), Day 4 (reminder), Day 6 (24h warning), Day 7 (expired + browse more). Never spam — each notification is useful.

Rule

10-Minute Redemption Window

Once "Slide to redeem" is triggered, the QR/code is valid for 10 minutes. Prevents screenshots being shared or replayed by others.

Revenue Impact

Why This Drives Revenue

Expiry → urgency → higher redemption rate → more value for merchants → lower merchant churn → more subscription revenue. The entire flywheel depends on coupons being USED, not hoarded.

Progress Bar

Visual Countdown

A thin progress bar under each card shows time remaining. Green (5+ days) → Orange (24h) → Red (6h). Subtle but effective — borrowed from game/streak mechanics.
